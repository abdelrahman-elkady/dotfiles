# Global preferences

- When blocked by a permission, classifier, or hook: stop and ask me directly. Don't improvise workarounds to route around the denial.
- Every path and URL is a markdown link: short display text, **full** target. Never a bare URL or relative path — I click these straight from the terminal.
  - Local: `[scratchpad/foo.md](/private/tmp/.../scratchpad/foo.md)` — target absolute.
  - GitHub: `[src/example.js#L10-L15](https://github.com/<org>/<repo>/blob/<full-sha>/src/example.js#L10-L15)` — full URL, full SHA.
